# Editorial layout terminology

For editorial magazine covers, spread layouts, and ad creatives with typography. Only consulted when `typography.present` is true.

## Anatomy of a magazine cover

```
┌─────────────────────────────────┐
│   MASTHEAD (title/logo)         │  ← top 15-20% of cover
│   ─ DATE / ISSUE # / PRICE ─    │
│                                 │
│        [HERO IMAGE]             │  ← full bleed or contained
│                                 │
│   COVER LINE 1 (large)          │  ← often overlapping image
│   cover line 2 (medium)         │
│   cover line 3 (small)          │  ← 3-6 cover lines typical
│                                 │
│  [Barcode]              [tagline]│  ← bottom margin
└─────────────────────────────────┘
```

## Masthead conventions

| Magazine | Masthead style | Font character |
|---|---|---|
| **Vogue** | Serif, wide letter-spacing, elegant | Didone / Didot-style |
| **Architectural Digest (AD)** | Slab serif, condensed, authoritative | Custom slab, tight tracking |
| **Dwell** | Sans, geometric, minimal | Neue Haas Grotesk family |
| **Wallpaper\*** | Sans, ultra-condensed, uppercase | Proprietary grotesque |
| **Cereal** | Sans, light weight, wide spacing | Airy modern grotesque |
| **The Gentlewoman** | Slab-like serif, distinctive, large scale | Custom slab |
| **Kinfolk** | Serif, refined, tight tracking | Transitional serif |
| **Apartamento** | Sans, irregular weight, quirky | Mixed weights |
| **Vanity Fair** | Serif, tall proportions, classic | High-contrast serif |
| **The New Yorker** | Serif, hand-lettered feel | Custom display serif |
| **Cabana** | Ornate serif, decorative flourish | Custom display |
| **Milk Decoration** | Sans, clean, low-key | Humanist sans |

Use the closest reference: "masthead styled like AD — slab serif, condensed, uppercase, authoritative" is more useful than "serif masthead."

## Font classifications

| Class | Feel | Examples |
|---|---|---|
| **Didone / high-contrast serif** | Elegant, fashion, luxury | Didot, Bodoni, Playfair |
| **Transitional serif** | Editorial, classic, refined | Garamond, Baskerville |
| **Slab serif** | Bold, architectural, authoritative | Rockwell, Archer |
| **Humanist sans** | Friendly, warm, readable | Gill Sans, Frutiger |
| **Grotesque sans** | Neutral, clean, modern | Helvetica, Neue Haas |
| **Geometric sans** | Technical, futuristic | Futura, Gotham |
| **Condensed sans** | Tall, bold, magazine-strong | Oswald, Bebas Neue |
| **Display serif** | Unique, decorative, branded | Custom display |
| **Script / handwritten** | Personal, luxury, wedding/invite | Copperplate, Snell |

## Cover line hierarchy

Editorial covers typically have 3-6 cover lines at varying scales:

1. **Hero cover line** — largest, 40-80pt, bold or heavy weight, often in accent color
2. **Secondary cover lines** — 20-40pt, regular or medium weight
3. **Small cover lines / tags** — 10-16pt, often uppercase, letter-spaced

The cover line block usually sits:
- Left third (vertical column)
- Right third (vertical column)
- Bottom third (horizontal band)
- Wrapping the hero subject (text-as-frame)

## Typographic treatments

- **Knockout**: white type on colored/image background
- **Solid**: full-color type on contrasting background
- **Outlined**: stroke-only letters
- **Drop shadow**: for legibility over busy images
- **Transparent overlay**: semi-opaque text blending with image
- **Text-as-image**: typography so large it is the hero element
- **Negative leading**: lines overlap slightly, graphic density

## Layout systems

- **Asymmetric grid**: editorial, energetic, modernist
- **Symmetric / centered**: classical, couture, luxury
- **Rule-of-thirds composition**: balanced, photographic
- **Full-bleed image + overlay type**: cinematic, dominant image
- **Split layout**: top half image, bottom half type (or vice versa)
- **Cropped type**: letters bleed off the page, bold editorial

## Whitespace and bleed

- **Full bleed**: image extends to edge of page, no margin
- **Contained bleed**: image has a white or colored border
- **Generous whitespace**: luxury, minimalist, Kinfolk feel
- **Tight whitespace**: dense, information-rich, supermarket magazine
- **Gutter** (print-only): space between facing pages, avoid losing content there

## Print artifacts (optional character)

- **Barcode**: usually bottom-left or bottom-right, 1 inch × ½ inch approximate
- **Issue number / date**: below masthead, small, uppercase, letter-spaced
- **Price + country**: below barcode or near masthead
- **Dateline**: month and year, near masthead
- **Tagline / subhead**: one line below masthead
- **Spine text** (print magazines): perpendicular to cover, title + issue

## Writing typography into prompts

Strong: `masthead in slab serif, uppercase, condensed — styled after AD — positioned top-center, color #FFFFFF, approximately 5% of vertical canvas. Hero cover line "THE QUIET HOUSE" in 72pt Didone uppercase, color #E8DCC4, positioned bottom-third-left, tight tracking. Three secondary cover lines below in 18pt Neue Haas Grotesk Medium, color #C9A961, uppercase, letter-spaced. Barcode bottom-right, small date marker top-left under masthead.`

Weak: `magazine cover with a title and some headlines`
