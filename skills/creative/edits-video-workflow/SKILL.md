# Edit short videos in Instagram Edits

Use the supplied footage and the current brief to make an editable timeline and a review MP4. For a revision, identify the active project by name and ID and save a baseline before changing it. Keep the user's chosen audio, caption placement, and prior approved decisions unless the current brief changes them.

1. **Inspect.** Identify the exact footage, audience, purpose, and review destination. Read the timeline on revisions. Probe the source frame rate, duration, dimensions, and color space. Transcribe dialogue locally and time cuts at phrase boundaries. Use another tool for a requested non-Edits editor.
2. **Source.** Inventory the supplied or authorized photos and video. Match visuals to what the speaker says at each time. Verify that each selected visual depicts the point you mean it to support. For footage shared in WhatsApp, use the installed `whatsapp-catchup` workflow when available and read only the requested chat and attachments. For a requested visual reference, watch the actual reference and apply its editorial pattern to the user's own media.
3. **Cut.** Make the argument and closing action easy to follow. Use the speaker's actual wording for captions. For a vertical talking-head clip, favor short captions above the face when the user wants room for visuals below. Keep readable contrast and use the actual frame to check placement.
4. **Overlay.** Map the footage to dialogue beats first. Use an ordered visual sequence (for example drawing review, reinforcement detail, site feedback, classroom training) when it clarifies the spoken point. Use real project imagery when requested. Keep the face and any call-to-action legible. When continuous overlays are requested, put the cutaways on a single lane and cover frame 0 through the final frame with exact adjacent edges. Run the coverage check in [the Edits runbook](references/edits-mac.md).
5. **Verify and deliver.** Save the intended project, confirm the sources are online, and render frames around cuts and at the ending. Export locally in the source's intended aspect ratio and color space. Check the exported duration, picture, captions, and dialogue. If the revision changes only overlays, compare the exported dialogue with the prior version. Leave the editable project open and hand over the verified review file. Local editing and export do not authorize publication.
6. **Archive.** In a Writer checkout, use the `video-work/` layout if present. Record the source inventory, cut or overlay plan, revision decisions, export paths, and checks. Keep raw media, editable project packages, review exports, credentials, and private source material in the appropriate local or private storage. Push work records only when asked.

Read [the Edits runbook](references/edits-mac.md) when connecting to the Mac app, importing assets, changing its timeline, or verifying an export. For a fresh task, ask only for a missing source or a decision that materially changes the edit.
