## Hard Rule

Treat the app UI and product behavior as locked during content production.

When Osiris says "work on the canvas," treat that as a content operation:

- Take the words, caption, headlines, and supporting copy and place them on the canvas.
- Arrange, split, size, align, and compose text layers so the post can be edited visually.
- Do not choose, replace, generate, or change visuals/background media unless Osiris explicitly asks for visual work.

Allowed without extra permission:

- Open and operate the existing app.
- Write/refine captions.
- Edit slide text inside the app.
- Move/resize/import visual objects inside the app.
- Use approved image libraries and default canvases.
- Export slides and copy captions.
- Create content folders, captions, briefs, images, and post assets.

Require explicit user permission before:

- Editing `carousel-engine.html` UI, CSS, JS, controls, layout, or product behavior.
- Changing the canonical product template.
- Adding new product features, sidebar controls, export behavior, or storage behavior.
- Reworking the brand system, fonts, caption preview, or slide engine.

If a UI/product issue blocks content work, describe the blocker and ask permission before changing code.

## Next Post Workflow

1. Read the user's idea and turn it into the caption first.
2. Keep the caption human: no unnecessary hashtags, no over-polished punctuation, no forced full stops after every sentence.
3. Build carousel logic around the caption; slides should be visual, emotional, and editable, not text dumps.
4. Open the canonical app and use it as the content director.
5. Put the approved words onto the canvas first; only touch visuals when Osiris asks for that.
6. Use existing controls to adjust slides, import images, move objects, export slides, and copy the caption exactly.
7. Save post artifacts in a clear company/post folder before handoff.

## Visual Direction

Use the Osiris tech brand blueprint for tone and visual taste. Prefer canvas-like visual thinking: paper, editorial typography, strong negative space, meaningful objects, sketches, diagrams, real references, and emotional visual canvases that leave room for headline/copy.
