# Implemented pattern candidates

These are working source examples from a real product pilot. Their status remains Trial until owner acceptance and suitable reuse are recorded.

| Need | Source | Status |
| --- | --- | --- |
| Open a named app with one accessible row | [App link markup and CSS](https://github.com/OsirisMedici/scale-design-system/tree/main/design-system/components/app-link) | Tested in the Scale Apps launcher |
| Copy the current page directory with visible feedback | [Copy-link markup, module and tests](https://github.com/OsirisMedici/scale-design-system/tree/main/design-system/components/copy-link) | Success UI and clipboard outcomes checked; native manual-fallback rendering remains open |
| Map warm paper, green ink and focus roles | [Opt-in pilot theme](https://github.com/OsirisMedici/scale-design-system/tree/main/design-system/foundations) | Used in Scale Apps; not a mandatory cross-product identity |

Read [the pilot's decisions and evidence](https://github.com/OsirisMedici/scale-design-system/tree/main/design-system/pilots/scale-apps) before reuse. Match the actual product's brand and behavior. Inspect the component's current source, copy only what fits and verify it in the adopting product.

The Scale Apps app-link example opens destination apps in new tabs by Osiris's explicit choice, keeping the launcher open. Preserve that contract when maintaining the launcher, and choose a navigation contract deliberately for other adopting products.
