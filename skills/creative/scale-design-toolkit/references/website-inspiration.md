# Website and landing-page inspiration

Collected from the accessible Canvas reference documents and the shared GitHub design library on 11 November 2026. These are saved references; external page availability and designs were not rechecked in this extraction. This is not an exhaustive scan of every private project or historical board.

## Start here

This index brings together 60 saved website/landing-page links, 40 MotionSites
example specifications, nine scrolling/motion resources and the source
collections. Use this page before searching Canvas and GitHub again for the
same references. The repository-resource catalog below is a capture; current
reviews remain in [the repository catalog](repositories.md).

For visual website examples, start with the six links below. For offer and
conversion-page structures, use the 54 landing-page examples. For scroll
techniques, use the motion section. The original Canvas boards remain linked
for their surrounding notes and future additions.

## Selected for Dynamic Solution

Osiris selected [Ather 450](https://www.atherenergy.com/450) for a simple page
with a guided, creative scroll that explains the whole company and what a
customer can buy. This is a project-specific choice, not a default for every
Scale website. Keep the client's own brand and content.

The company page uses WhatsApp for enquiries; surveys were deferred. Project
implementation and release evidence live in the
[company-page brief](https://github.com/OsirisMedici/client-marketing-sites/blob/main/clients/dynamic-solution/storage-tanks/COMPANY-PAGE.md).
The [published page](https://dynamic-solution-tanks.vercel.app/company/) is a
working project example. Osiris has not yet accepted its final visual design.

Ather is an additional selected reference and is not included in the count of
60 links recovered from the earlier saved collections.
