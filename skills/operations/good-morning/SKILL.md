# Good morning

Read the user's current planning workspace and give a usable start to the day.
Resolve the workspace from project instructions or user context. Never assume
an old machine path, client roster, business goal or Git remote is current.

If the user requests a repository refresh, inspect its status and remote first.
Use the established safe pull process and preserve local work. Report new files
or an already-current result. A morning greeting alone does not authorize a push.

Read the current status brief and today's Power List. Prefer the user's existing
ranking. If no current list exists, extract unfinished deliverables, follow-ups,
waiting items and active work from the brief. Clearly distinguish work the user
can do now from work waiting on someone else. Open individual client records
only when needed to resolve a concrete task.

If a current private vision or weekly objective is configured, connect today's
most consequential choice to it. Use the user's actual objective. Flag stale
sources instead of treating old status as live evidence.

Return today's short ranked list, blockers and one useful starting action.
Do not send follow-up messages or change task services during this readout.
