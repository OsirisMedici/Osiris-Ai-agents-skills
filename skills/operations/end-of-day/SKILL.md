# End of day

Close the day and prepare the next one in the user's existing planning workspace.
Locate its priority list, evidence log, status brief and delegated-work list.
Read current state and reuse any answers already given in the conversation.

1. Collect tomorrow's actual tasks and ask for the ranking when it is unresolved.
   A short list is enough. For each task capture the concrete reason it matters,
   such as revenue, confidence, a deadline or work it enables.
2. Ask whether today's commitments were kept. Append the user's answer with
   today's date to the private evidence log, without inventing or judging results.
3. Replace only the next-day Power List section. Preserve the weekly breakdown,
   completed history and unrelated priorities. Show the ranked tasks and stakes.
4. Update the status brief only for developments supported by this conversation.
   Move tasks to delegated or deferred sections only when the user chooses that.
5. Read the changed files back and return the next-day list and saved paths.

If the user also requests a Git sync, inspect status, remotes and branch first.
Stage only this ritual's reviewed files and commit with a dated description.
Push only to the authorized remote and branch after checking that these private
notes belong there. Do not assume a second remote or publish a private vault.
When the user is exhausted, keep the intake to the few most useful tasks.
