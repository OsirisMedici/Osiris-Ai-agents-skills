# Make a list

1. Read the resolved private Markdown master for existing list names and entries. Preserve any original import as a frozen backup; write requested changes to the existing master.
2. Resolve the requested titles. For a YouTube link, use the linked video unless the user asks for its whole playlist. Open it in the in-app Browser and use the supported YouTube transcript export when available, then check chapters, the description, or the video for unclear names. Auto captions can mishear titles. Distinguish recommendations from incidental mentions and follow the user's scope. When asked for every show mentioned, include named comparisons and examples. Use a catalog to confirm ambiguous names, years, and film or series identity. Keep uncertain matches out of the saved list and report them.
3. Save in a `## List name` section in the master. Keep the supplied title order or source order and deduplicate by movie/series identity within that list. A title can belong to several lists. Use one Markdown bullet per entry, with year and a TMDB identity link when verified. Add the source link once per group of sourced entries. Reuse a section for an explicit add or retry. If the user requests a new list with an existing name, keep both lists distinct and state the chosen name.
4. Read the section back. Verify the titles, order, and count against the intended set. Save the requested additions in Cinejoy unless the user says local only. Link the local file and the Cinejoy list view, and report unresolved titles or any difference between the two.

## Cinejoy private list view

Open [My Lists](https://cinejoy.pk/lists) in the in-app Browser and inspect the named list and its contents first. Reuse the matching private list when the request adds to it or retries it. Use New List if required. Search for each missing title, choose the right media type and year, and use Add to list on the detail page. Wait for the detail page to settle and confirm the picker is open before choosing the list. The picker can toggle membership. If the result is uncertain, inspect the list before clicking again. Reopen the list and verify the requested entries. Keep additions scoped to this run. Leave sharing and other streaming-site lists alone. If Cinejoy is unavailable, keep the local save and report the pending UI additions.
