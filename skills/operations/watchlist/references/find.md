# Find playback

1. Resolve the exact movie or series, release year if ambiguous, and requested season, episode, and language. A matching active watch page can supply a missing episode. If only a series is named and no matching episode is in context, test season 1 episode 1 and say so. Use India for region-specific checks unless the user gives another region. A reported failure applies to that attempt. Skip the known failing site unless diagnosis is requested.
2. Open [TBCPL](https://tbcpl.lol/) in the in-app Browser for current candidates. Use Anime or Movies & Shows as appropriate. Check the directory's displayed region and use the requested region if supported. A directory link or badge is discovery evidence. Also check a direct official provider when it offers the requested episode in the user's region. Prefer a verified link that meets the user's access and language needs. Use the site's search and episode controls to reach the correct watch page.
3. Test a small set of distinct providers in the in-app Browser. Start with a promising candidate and one backup. If a server stalls, try a visible alternate for the same episode or move on. Prefer purpose-built tools when they can verify the same outcome. Use ordinary browser controls and stop at browser security blocks, unexpected redirects, or sign-in, subscription, or region barriers. Continue with another candidate when useful. Avoid changing accounts, settings, or watchlists for this lookup.
4. Verify the actual episode. Confirm playback with two observations of the media clock advancing during the episode, or with visible episode frames and a changing player timestamp. The catalog, player shell, poster, trailer, ads, and a static duration do not establish playback. If the player can't be observed, label the result episode listed, playback unverified. Record the language and server only when observed.
5. Return the strongest exact episode link first, with the playback status and any server step needed. Include at most one useful backup unless asked for more. If no stream starts, report the best verified catalog link and the concrete access or playback blocker. A successful check applies to that episode and time.
