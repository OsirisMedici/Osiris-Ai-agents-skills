# Client Research — Brand + Company Overview Folder

## Public setup

Resolve the user's authorized workspace before following file paths below.
`<workspace>` and named vault folders describe an existing layout, not bundled
data. Reuse equivalent files in the user's setup. Ask for a destination only
when discovery cannot resolve it. Private records and reference documents must
be supplied or located locally; do not invent their contents. Reuse answers
already in the request rather than repeating the intake. Use available supported
tools and the visible in-app Browser for browser work. Installing this skill
does not invoke it or authorize messages, publishing or unrelated service writes.

## Overview

Before writing a single word of strategy or copy for a new client, build a research folder. Research the brand before developing its strategy.

The folder lives at: `Clients/[Client Name] - [Contact]/[Client Name] — Research/`

---

## The 9-File Structure

| File | Contents |
|---|---|
| `01 — Company Overview.md` | Basic facts, leadership, services, philosophy, "What They Say vs What They Do", market positioning |
| `02 — Portfolio + Projects.md` | Full project list by sector, flagship projects, portfolio observations |
| `03 — Awards + Press.md` | All awards with year/category, press coverage found, coverage gaps, unpursued press opportunities |
| `04 — [Industry] Sector + Market Context.md` | Market size + drivers, client pain points, budget realities, why the category matters |
| `05 — Competitors + Market Position.md` | Direct competitors by tier, head-to-head comparison table, where client wins, where they lose, positioning gap |
| `06 — Social Media + Digital Presence.md` | All platform handles + metrics, content themes, tone, bio analysis, digital presence score + priority fixes |
| `07 — [Founder(s)] — Voice + Philosophy.md` | Background, public quotes, inferred communication style, what the voice means for messaging |
| `08 — ICP Inputs + Marketing Gaps.md` | Primary avatar (who/what they want/fear/feel), secondary avatar, ranked marketing gaps with fixes |
| `09 — Research Summary.md` | One-line version, company snapshot, real competitive advantages, marketing problem, what we're building, key people |

## Research Process

### Step 1 — Check existing client files first
Read what's already in the client folder. Don't re-research what's already documented.

### Step 2 — Check reference folder format
Read one existing research folder in the authorized workspace to match the format exactly before writing.

### Step 3 — Web research (run searches in parallel)

**Search queries to run:**
- `[Client Name] architecture/firm/company India`
- `[Client Name] [Founder Name] portfolio awards`
- `[Client Name] Instagram social media presence`
- `[Industry] architecture firms India competitors [city] [year]`
- `[Client Name] awards recognition press coverage`

**Pages to fetch:**
- `[website]/about-us` — company history, philosophy, founder bio, stats
- `[website]/our-team` — all team members, roles, backgrounds
- `[website]/` — homepage taglines, service areas, featured projects, stats
- `[website]/projects` — full project list with sectors, locations, years
- `[website]/awards` (if exists) — full awards list
- LinkedIn company page — followers, employee count, recent activity
- Competitor websites — 2–3 to understand what client is up against

### Step 4 — Write files in this order
01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09

Write 09 (Research Summary) last — it synthesizes everything.

---

## Key Analysis Patterns

### "What They Say vs What They Do"
Always include in file 01. Find the gap between positioning language and actual portfolio.
- They say "sustainable luxury" → they do government institutional buildings
- They say "17-person team" → they show 4 named senior leads

### "Where They Actually Win" Table (file 05)
Build a comparison table. Columns: Factor | Client | Competitors. Use ✓ / ✗.

### Digital Presence Score (file 06)
Rate 1–10. Be honest. Most clients are 3–5. Include the reason and top 3 fixes.

### Marketing Gaps (file 08)
Rank by impact. For each gap:
- **What's missing** — the specific absence
- **Why it matters** — consequence if unfixed
- **Fix** — one concrete action

### The "One-Line Version" (file 09)
Start the Research Summary with a single sentence that captures the brand vs. reality gap. This is the frame for all future work.
