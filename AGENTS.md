# Repository contract

Maintain a private library of reusable social and campaign operations skills.

- Follow the skill-creator workflow when creating or substantially revising a skill.
- Put skills in `skills/<platform>/<skill-name>/`; the folder and frontmatter name must match.
- Keep entrypoints focused. Use supporting references only for material that changes execution decisions.
- Preserve the user's task-specific authorization. A skill is not permission to access another account, publish, change delivery, or perform unrelated writes.
- Store only generalized instructions and fictional examples here. Keep client mappings, approvals, IDs, URLs, exports, screenshots, credentials and browser state in the authorized task workspace.
- Keep this repository private. Do not add a public license or broaden sharing without the owner's request.
- Validate changed skills and execute meaningful checks for changed helpers. Distinguish offline validation from live browser acceptance.
- Do not copy unrelated personal skills into this repository merely because they are installed locally.
